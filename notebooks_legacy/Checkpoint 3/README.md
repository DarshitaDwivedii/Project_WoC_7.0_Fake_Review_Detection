# 🌟 Checkpoint 3: Web Scraping for Reviews 

## 🚀 About the Project
This Python script scrapes product reviews from Amazon, filters them by star ratings (1⭐ to 5⭐), and saves the review content and ratings in a CSV file.

---

## 🛠 Features
- ✅ Extracts reviews by rating (1⭐, 2⭐, 3⭐, 4⭐, 5⭐).
- ✅ Stores only review content and numeric rating.
- ✅ Saves the data in a clean, easy-to-read **CSV file**.

---

## 📦 Requirements
- Python 3.x
- Libraries: `requests`, `beautifulsoup4`, `csv`, `re`
